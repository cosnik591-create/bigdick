# Монополия — сетевая настольная игра

Учебный проект: классическая «Монополия» с сетевым мультиплеером.
Клиент и сервер написаны на Python, интерфейс — на [Arcade](https://api.arcade.academy/).
Сервер авторитетный: клиенты присылают действия, а состояние партии
рассчитывается и рассылается на сервере.

Уже работают меню, лобби, чат и базовая экономика «Монополии»: покупка
собственности, аренда, аукционы, дома и отели, залог, тюрьма, налоги,
карточки «Шанс»/«Казна» и банкротство.

## Что уже работает

- Главное меню с сохранением имени игрока.
- Хостинг: компьютер игрока поднимает встроенный TCP-сервер.
- Подключение по адресу `IP:порт` и коду лобби.
- До 6 игроков в лобби, готовность, чат, исключение игроков.
- Анимация броска кубиков и плавное перемещение фишки.
- Покупка клетки или отправка её на аукцион.
- Пошаговый аукцион со ставками и пасом.
- Рента по стандартным правилам: улицы, полная цветовая группа,
  железные дороги и коммунальные предприятия.
- Дома и отели с равномерной застройкой и лимитами банка.
- Продажа зданий, залог и выкуп собственности.
- Тюрьма: посещение, отправка в тюрьму, залог, карта освобождения,
  дубль и три неудачные попытки.
- Налоги, «Шанс» и «Казна» с набором базовых карточек.
- Банкротство с передачей имущества кредитору или банку.
- Победа последнего платёжеспособного игрока.
- Сервер умеет держать несколько лобби одновременно (UI создаёт одно).

## Требования

- Python 3.10+
- Arcade 3.3+ (устанавливается через pip)
- OpenGL 3.3+ и видеодрайвер
- Linux, Windows или macOS

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 main.py
```

## Как играть по сети

1. Хост нажимает **«Создать лобби»**, задаёт имя, порт (по умолчанию 8765)
   и число игроков.
2. На экране лобби появляется **код** и **адрес** вида `192.168.0.5:8765`.
3. Остальные запускают игру, нажимают **«Подключиться»** и вводят этот адрес
   и код.
4. Гости нажимают **«Я готов»**. Когда готовы все, хост нажимает
   **«Начать игру»**.

### Локальная сеть

- Все компьютеры должны быть в одной сети.
- Если соединение не устанавливается, разрешите входящие подключения
  для Python/порта 8765 в файрволе.
- Адрес показывается автоматически, но при нескольких сетевых интерфейсах
  (VPN, Docker) может выбраться «не тот». Тогда посмотрите IP вручную:
  `ip addr` / `ipconfig`.

### Через интернет

Нужен проброс порта (port forwarding) на роутере хоста: внешний порт →
`IP_хоста:8765`. Друзьям нужно сообщить внешний IP и код лобби.
Автоматического NAT traversal и выделенного сервера пока нет.

### Проверка на одном компьютере

Можно запустить два экземпляра игры. Первый создаёт лобби, второй подключается
к `127.0.0.1:8765` (или к показанному локальному адресу).

## Управление и ход игры

- Мышь — кнопки, поля ввода и клетки поля.
- **Клик по клетке** открывает карточку собственности. На своей клетке
  в свой ход можно построить/продать здание, заложить или выкупить участок.
- На некупленной клетке при остановке появляется окно: купить или выставить
  на аукцион.
- Во время аукциона кнопки ставок и «Пас» показываются только тому, чья
  очередь.
- В тюрьме доступны бросок на дубль, залог 50 ₽ и карта освобождения.
- `Enter` — отправить сообщение в чате лобби.
- `Пробел` — пропустить анимацию броска/хода.
- `Esc` — закрыть карточку/подтверждение или выйти из партии.

Строить и закладывать можно **до броска кубиков** в свой ход. После броска
ход автоматически переходит дальше, кроме случая дубля.

## Сетевой протокол

TCP, по одному JSON-объекту на строку (UTF-8, `\n` в конце).
У каждого сообщения есть поле `type`.

Клиент → сервер:

```json
{"type":"create_lobby","name":"Аня","lobby_name":"Вечерняя партия","max_players":4}
{"type":"join_lobby","name":"Борис","code":"AB3D"}
{"type":"set_ready","ready":true}
{"type":"start_game"}
{"type":"chat","text":"Привет!"}
{"type":"roll_dice"}
{"type":"buy_property"}
{"type":"decline_property"}
{"type":"auction_bid","amount":120}
{"type":"auction_pass"}
{"type":"build","position":1}
{"type":"sell_building","position":1}
{"type":"mortgage","position":1}
{"type":"unmortgage","position":1}
{"type":"pay_jail"}
{"type":"use_jail_card"}
{"type":"leave_lobby"}
{"type":"kick_player","player_id":"p12ab34cd"}
{"type":"ping"}
```

Сервер → клиент:

```json
{"type":"hello_ok","player_id":"p12ab34cd","version":2,"app_version":"0.2.0"}
{"type":"lobby_state","lobby":{...}}
{"type":"chat_message","player_id":"p...","name":"Аня","text":"Привет!","ts":1760000000.0}
{"type":"game_started","game":{...}}
{"type":"game_update","game":{...}}
{"type":"game_aborted","reason":"В игре осталось меньше двух игроков"}
{"type":"error","code":"game_error","message":"Недостаточно денег для покупки"}
```

В `game_update` передаются фаза (`await_roll`, `purchase`, `auction`,
`game_over`), игроки с деньгами и тюрьмой, все объекты собственности,
текущий аукцион и журнал.

Все изменения проверяются на сервере: хост-права, очередь хода, наличие
денег, правила застройки, ставки и лимиты. Клиент не может «подкрутить»
баланс или собственность.

## Правила и упрощения текущего этапа

- Налоги фиксированные: подоходный — 200 ₽, роскошь — 100 ₽.
- «Шанс» и «Казна» используют базовый набор карточек, а не полные
  классические колоды.
- В колоду «Шанс» добавлены специальные карточки: срочный сбор обнуляет
  счёт; программа расселения забирает случайную собственность в банк;
  «кредит бабушки» требует срочно оплатить сумму от 50% до 200% текущего
  счёта (при нехватке денег — банкротство).
- Бесплатная парковка не собирает банк штрафов.
- При нехватке денег банкротство наступает сразу: закладывать и продавать
  имущество нужно заранее, в свой ход до броска. Автоматической распродажи
  активов для оплаты долга нет.
- Сделки и торги между игроками не реализованы.
- Имущество банкрота при долге банку возвращается в банк, а не разыгрывается
  на аукционе.
- Нет переподключения к начатой партии.
- Чат отображается только в лобби.
- Нет браузера открытых лобби: подключение по коду и адресу.
- Звука пока нет.

3. Полные колоды «Шанс»/«Казна» и правила аукциона при банкротстве.
4. Переподключение и восстановление партии.
5. Чат в игре и прокручиваемый журнал.
6. Браузер лобби и отдельный выделенный сервер.
7. Звук и более богатые анимации.
